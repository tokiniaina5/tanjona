Partager sur les réseaux sociaux

Envoyez votre lien directement sur un réseau social. Dès que votre ami ouvre l'application via ce lien, il est automatiquement compté dans « Vos parrainages » ci-dessus — aucune confirmation manuelle n'est nécessaire de votre part.

Utilisez {lien} et/ou {message} dans l'URL : ils seront remplacés automatiquement par votre lien d'invitation et le message. Si le réseau ne propose pas d'URL de partage, laissez ce champ vide : le message sera simplement copié.

Instagram, TikTok et WeChat ne permettent pas de préremplir un message depuis un site web : votre message est copié automatiquement, il ne reste qu'à le coller dans la discussion.
